# 我的自传

> 一个农村孩子的觉醒之路

## 简介

1992年农历11月，我出生在中国湖南的一个农村家庭。父亲是砖厂老板，后失败进煤矿，再南下广东打工；母亲1965年生，操持家务。我有个大两岁的哥哥。

从小学年级第一，到高考考入北京工商大学，再到计算机硕士、京东工作、阿联酋哈利法大学读博——2021年疫情后的人生彻底改写。

这本书记录我的人生轨迹，特别是2021年之后的觉醒与成长。一个农村来的孩子，在被洗脑的人生中慢慢清醒，懂了时间的不公平、赚钱的本质、男女的情爱。
